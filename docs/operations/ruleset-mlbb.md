# MLBB ruleset — working draft

This document is a **structure**, not the final ruleset. Tournament-specific values should be approved before registration opens.

## 1. Eligibility

Define:

- player age requirements, if any;
- geographic restrictions, if any;
- account requirements;
- banned/suspended player policy;
- whether one player may appear on more than one roster.

## 2. Rosters

Default working model:

- 5 starting players;
- up to 1 substitute;
- one designated captain.

Roster-lock timing is still TBD.

## 3. Match format

Still TBD:

- bracket type;
- number of teams;
- BO1 / BO3 / BO5 structure;
- grand-final format;
- third-place match.

## 4. Lobby procedure

Staff should publish:

- lobby credentials;
- assigned side/team order;
- draft/start instructions;
- deadline for joining.

## 5. Disconnects and technical issues

Define clear restart/remake criteria before the tournament. Decisions should depend on observable game state and documented rules rather than ad-hoc negotiation.

## 6. No-shows

Set:

- grace period;
- contact attempts required;
- forfeit threshold.

## 7. Result reporting

Captains submit the result. Referee/operator verifies before the match becomes final.

## 8. Disputes

A dispute should include:

- match ID;
- rule allegedly violated;
- concise description;
- evidence;
- requested review.

Tournament staff make the final operational ruling under the published ruleset.

## 9. Conduct

Prohibit harassment, deliberate disruption, impersonation, match fixing, cheating and unauthorized account use.
